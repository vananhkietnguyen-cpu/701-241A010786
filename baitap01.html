Trang Trả Lời Chi Tiết Phần Lý Thuyết (40 Điểm)

Câu 1 (10 điểm): Position absolute / relative, Responsive & Hosting

1. Sự khác biệt:

  • position: relative: Dịch chuyển so với vị trí ban đầu của chính nó, không làm mất khoảng trống (flow) ban đầu trên layout.
  • position: absolute: Tách khỏi dòng chảy tự nhiên của trang web, định vị dựa vào phần tử cha gần nhất có `position` khác `static`.

2. Ví dụ Responsive (Card sản phẩm có nhãn Badge):

.card { position: relative; width: 100%; max-width: 300px; }
.badge { position: absolute; top: 10px; right: 10px; background: red; color: white; }

3. Ảnh hưởng khi Deploy lên Hosting: Nếu không đặt `relative` ở thẻ cha, thẻ con `absolute` sẽ lấy mốc từ góc trang web (`body`), dẫn tới vỡ giao diện trên các thiết bị mobile khác nhau.

Câu 2 (10 điểm): Quy trình Đăng ký Domain, Hosting, DNS & Security

1. Quy trình: Mua tên miền -> Đẩy mã nguồn JavaScript/HTML lên Server Hosting -> Cấu hình bản ghi A Record hoặc CNAME trên DNS để trỏ tên miền về IP/Host.

2. Vai trò DNS: Chuyển đổi tên miền dễ nhớ (vd: `domain.com`) thành địa chỉ IP máy chủ (vd: `192.0.2.1`).

3. 2 Công cụ Deploy không cần Server: GitHub Pages & Netlify (hoặc Vercel).

4. Rủi ro bảo mật: Nếu thiếu SSL/HTTPS sẽ làm lộ thông tin truyền nhận; để lộ API Key client-side trong file `.js` sẽ bị kẻ xấu lợi dụng.

Câu 4 (10 điểm): Event Delegation & Tối ưu hiệu suất

Khái niệm: Lợi dụng cơ chế Event Bubbling để gắn 1 Event Listener duy nhất vào phần tử cha thay vì gắn vào từng phần tử con.

Ví dụ với danh sách động:

document.getElementById('parent-list').addEventListener('click', function(e) {
    if(e.target && e.target.classList.contains('btn-delete')) {
        e.target.parentElement.remove();
    }
});

Lợi ích: Tiết kiệm RAM bộ nhớ, tối ưu tốc độ render, tự động nhận sự kiện cho cả các phần tử con được thêm mới sau này bằng JS.
